# Fixtures

Small inputs for the tests and the examples. Each file is either generated by
a script in this repo or written by hand.

Generated:
- `click-100bpm.wav`: a 20 s mono 44.1 kHz click track at 100 BPM, made by
  `scripts/make-fixtures.sh` (needs ffmpeg only).
- `captures/*/capture.*` and `receipt.json`: recordings of the demo apps below,
  made by `fixtures/make-fixtures.js` (needs Chrome).

Written by hand (HTML, text and JSON):
- `demo-app/`, `highlight-app/`, `real-app/`, `device/`: tiny HTML apps and
  flows that the capture and device tests drive.
- `brand/`: logos of a made-up brand.
- `real/`: capture JSON and flows for the "real video" tests.

- `footage-abstract.mp4`: drifting colour gradients (no camera footage), generated by
  `scripts/make-fixtures.sh` with ffmpeg. Used by the `type-window`, `ascii-cam` and
  `kinetic-captions` examples as a stand-in background video.
- `real/*/capture.mp4`: browser captures of the made-up demo app in `real-app/`
  ("Kvikk"), served on 127.0.0.1 in a 360x672 phone-sized viewport, then framed as
  a phone recording by `scripts/real-fixture.js` (it adds status, toolbar and nav bars). Every name and amount in it is invented. Each
  `receipt.json` holds the SHA-256 of its capture.
