# Bundled font licences

Every file in `fonts/files` was checked against the licence URL and copyright
string in its own name table (nameIDs 0 and 14). Most are SIL Open Font
License 1.1 (full text: [OFL.txt](OFL.txt)). One is Apache-2.0 (full text:
[APACHE-2.0.txt](APACHE-2.0.txt)). None of the copyright lines declares a
Reserved Font Name.

The fonts are redistributed unmodified. Rendered video is not a derivative of
the font files under either licence.
